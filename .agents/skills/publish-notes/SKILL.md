# Publish Notes

用于发布由 [lecture-to-notes](https://github.com/ysyecust/lecture-to-notes) 生成的笔记 PDF。本技能负责发布，不负责生成笔记。按当前环境已有的仓库与授权方式操作；不依赖未随仓库提供的其它技能或专用工具。

1. 确认输入：从用户及已有上下文确定目标仓库、课程和最终 PDF；记录来源 URL、讲次、页数、字节数、SHA-256，并检查验证报告。
2. 统一命名：使用英文小写文件名，例如 `<course>_01_getting_started_zh.pdf`。保留中文展示标题。重命名不改变 PDF 内容。
3. 上传文件：使用当前环境获准的仓库通道。已在该仓库工作的 Cloud Agent 只是一种可选方式。GitHub App 授权不等于本地 `gh` 登录，不要因此索要密码。按当前附件限额分批上传，只包含最终笔记和必要元数据。
4. 更新网站：遵循现有目录结构，同步课程元数据、目录、统计、缩略图及 PDF 路径；保留已有内容、阅读器和许可证。测试根路径和部署子路径，实际打开首尾两讲，核对全部新 PDF 哈希。
5. 提交与合并：新发布使用新分支和 PR，同次修改复用原 PR。尽量首次推送前整理为一个提交。经用户批准后，先把该 PR 的提交 squash 成一个，再 rebase 合并。已推送历史的改写须单独说明并获确认，不擅自强推。
6. 验证上线：等待部署成功，核对线上目录、阅读器、缩略图和全部新 PDF 哈希，再交付阅读链接。明确区分已提交 PR、已合并和已上线。
